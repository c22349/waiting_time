# Google Play ストア掲載情報（下書き）

そのままPlay Consoleにコピー&ペーストして使えます。文字数はGoogle Playの上限に収まるよう調整済みです。

## アプリ名（30文字以内）
```
キュータイム - 行列の待ち時間予測
```
(15文字)

## 簡単な説明（80文字以内）
```
リトルの法則で行列の待ち時間をかんたん予測。前の人数と1分間の増加人数を入力するだけ。
```

## 詳細な説明（4000文字以内）
```
「キュータイム」は、行列に並んでいるときに残りの待ち時間をかんたんに予測できるアプリです。

■ 使い方はシンプル
1. 前に並んでいる人数をカウントして入力
2. 1分間タイマーで後ろに並んだ人数をカウント
3. 「計算」ボタンを押すだけで、予想待ち時間が表示されます

■ リトルの法則を活用
行列理論で知られる「リトルの法則」を用いた簡易計算により、行列の増加スピードから待ち時間を予測します。専門的な知識は不要、誰でもすぐに使えます。

■ こんな場面で便利
・テーマパークやイベントの行列
・人気店の開店待ち・順番待ち
・混雑する窓口・施設の待ち時間確認

■ 主な機能
・シンプルな2ステップ入力
・1分間の計測タイマー内蔵
・日本語 / English 対応
・タイマー終了のアラーム音設定

待ち時間が分からず不安なときも、キュータイムがあれば見通しが立てられます。ぜひお試しください。
```

## その他の入力項目
- カテゴリ: ツール または ライフスタイル
- 連絡先メール: （実際のメールアドレスに置き換え）

- 広告の有無: 「はい」（AdMobを使用）
- 対象年齢層: 全年齢
